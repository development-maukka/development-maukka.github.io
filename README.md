# Development Maukka – GitHub Pages portal

Starter portal for `https://development-maukka.github.io/`.

## Publish
1. Create or open the public repository `development-maukka/development-maukka.github.io`.
2. Upload **the contents** of this ZIP to the repository root (`index.html` must be at the root).
3. Commit the files.
4. Go to **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Open `https://development-maukka.github.io/` after deployment completes.

## Releases
This starter intentionally contains no APKs and no invented download links. Add actual release links only after approving each published APK. Keep all APK versions in GitHub Releases and implement update notifications in the Android apps separately.

## Languages
Finnish, German and English selected from browser/device language; other languages default to English.
